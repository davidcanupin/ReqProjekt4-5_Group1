FA3 – Epics & User Stories “EV Charging Network”

Requirements Engineering Project · Group 1 · Version 1.0 (draft) · based on IA2 User Story Map MVP

Each Epic is derived from the narrative flow (Backbone) of the User Story Map and represents the scope of one future BDD Feature File. Each User Story corresponds to exactly one task of the User Story Map. Format: As <user> I want <function> so that <value>. All terms follow the Glossary (FA1).

E1Location ManagementAs Owner, I want to manage Locations, so that I can represent the sites of my EV Charging Network in the system.
IDUser StoryPriority
US01As Owner, I want to create Location, so that a new site of my EV Charging Network is available in the system.MVP
US02As Owner, I want to read Locations, so that I have an overview of all my Locations.MVP
US03As Owner, I want to update Location, so that Location data stays correct.Backlog
US04As Owner, I want to delete Location, so that closed sites are removed from the EV Charging Network.Backlog
E2Charger ManagementAs Owner, I want to manage the Chargers of each Location, so that Customers can charge their vehicles with AC or DC.
IDUser StoryPriority
US05As Owner, I want to create Charger, so that a new AC or DC Charger can be used at a Location.MVP
US06As Owner, I want to read Chargers, so that I know which Chargers exist at each Location.MVP
US07As Owner, I want to update Charger, so that Charger data (e.g. Charging Mode) stays correct.Backlog
US08As Owner, I want to delete Charger, so that removed Chargers are no longer offered.Backlog
E3Price ManagementAs Owner, I want to manage the Price List of each Location, so that Charging Sessions are billed correctly and I can react to market changes.
IDUser StoryPriority
US09As Owner, I want to create Price List, so that Charging Sessions at a Location can be billed.MVP
US10As Owner, I want to read Price List, so that I know the currently valid Prices of a Location.MVP
US11As Owner, I want to update Price List, so that new Prices apply to Charging Sessions started afterwards.MVP
E4Charger Status ManagementAs Owner, I want to manage the Charger Status, so that only usable Chargers are offered to Customers.
IDUser StoryPriority
US12As Owner, I want to set Charger Out of Order, so that a defective Charger cannot be used.MVP
US13As Owner, I want to set Charger Available, so that a repaired Charger can be used again.MVP
E5Network StatusAs Owner / Customer, I want to view the Network Status at any time, so that I know the current Price Lists and which Chargers are available.
IDUser StoryPriority
US14As Owner, I want to read Network Status, so that I see Price Lists and Charger Status of all Locations.MVP
US15As Owner, I want to filter Network Status by Location, so that I can quickly check one Location.Backlog
US16As Customer, I want to read Network Status, so that I can find an Available Charger and its Prices.MVP
US17As Customer, I want to filter Network Status by Location, so that I only see Chargers near me.Backlog
US18As Customer, I want to filter Network Status by Charging Mode, so that I only see AC or DC Chargers.Backlog
E6Customer Account ManagementAs Customer, I want to register and manage my Customer Account, so that I can use the EV Charging Network.
IDUser StoryPriority
US19As Owner, I want to read Customer Accounts, so that I know who is registered in my EV Charging Network.MVP
US20As Owner, I want to deactivate Customer Account, so that misused Customer Accounts can be blocked.Backlog
US21As Customer, I want to create Customer Account, so that I can use the EV Charging Network.MVP
US22As Customer, I want to read Customer Account, so that I can check my registered data.MVP
US23As Customer, I want to update Customer Account, so that my data stays up to date.Backlog
US24As Customer, I want to delete Customer Account, so that my data is removed when I stop using the service.Backlog
E7Top-UpAs Customer, I want to top up my Customer Account in advance, so that I have enough Balance to charge (prepaid system).
IDUser StoryPriority
US25As Customer, I want to top up Customer Account, so that I have enough Balance to start a Charging Session.MVP
US26As Customer, I want to read Balance, so that I know how much money is left.MVP
E8Charging SessionAs Customer, I want to charge my vehicle at a Charger, so that my vehicle has enough energy and the Charging Cost is billed automatically.
IDUser StoryPriority
US27As Customer, I want to start Charging Session, so that my vehicle is charged at the Prices valid at the start.MVP
US28As Customer, I want to end Charging Session, so that the Charging Cost is calculated and deducted from my Balance.MVP
US29As Customer, I want to read running Charging Session, so that I see Charged Energy and Charging Duration so far.Backlog
E9Transaction HistoryAs Customer / Owner, I want to view the Transaction History of a Customer Account, so that Top-Ups, Charging Costs and the Balance are transparent.
IDUser StoryPriority
US30As Owner, I want to read Transaction History of a Customer, so that I can check Top-Ups, Charging Costs and Balance of a Customer.MVP
US31As Owner, I want to filter Transaction History by period, so that I can analyse a specific time range.Backlog
US32As Customer, I want to read Transaction History, so that I can check all my Top-Ups, Charging Sessions and my Balance.MVP
US33As Customer, I want to filter Transaction History by period, so that I can review a specific month.Backlog
